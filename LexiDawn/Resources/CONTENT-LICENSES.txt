Bundled dictionary

No dictionary network provider, user dictionary import, MDD, image, or audio dependency is used. Pronunciation uses iOS system speech.
User-created senses are labelled personal content and remain distinct from the MDX source.
Historical external-provider records remain in upgraded databases for provenance only and are excluded from current lookup and new review questions.

HTML named character reference data
html-entities.json maps standard HTML5 character-reference names to Unicode characters, generated from Python standard library html.entities.html5 (PSF-licensed standard-library data; WHATWG HTML named character reference mappings). It contains character mappings only, not article or dictionary content. No network calls are made while decoding entities.
