# Dictionary Data

本目录用于在**授权范围内**保存和重组词典数据文件。

> **当前状态：** 本目录先提供拆分、合并和校验工具；原始二进制数据及其分块尚未上传。不要把本目录误认为已经包含完整词典数据。

## 文件

- `split.py`：将本地原始文件拆成多个二进制分块，并生成 `manifest.json`。
- `merge.py`：根据清单按顺序合并分块，并校验每个分块及最终文件的 SHA-256。
- `*.part*`：运行拆分脚本后生成的数据分块（当前仓库中尚不存在）。

## 拆分

需要 Python 3。将原始文件放在仓库根目录（示例文件名为 `dic_data(1)`），然后在本目录运行：

```bash
python3 split.py "../dic_data(1)"
```

默认每块 4 MiB。可用 `--chunk-size` 调整，例如：

```bash
python3 split.py "../dic_data(1)" --chunk-size 2097152
```

拆分完成后，本目录会生成 `dic_data.part0001`、`dic_data.part0002` 等文件，以及 `manifest.json`。

## 合并

在本目录运行：

```bash
python3 merge.py --output "../dic_data_restored"
```

合并程序会先校验每个分块，再校验最终文件的总字节数和 SHA-256。全部校验通过后才会生成目标文件；任何校验失败都会报错。
