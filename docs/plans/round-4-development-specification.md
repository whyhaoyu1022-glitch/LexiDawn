# Round 4 产品范围与验收合同

Round 4 覆盖 P01–P21 与三项词典补充。需求编号、24 个测试族和 144 条可核对标准来自[反馈清单](../reviews/round-4-feedback-manifest.json)。本文按功能说明实际要交付的行为。完整原句和独立验收状态见[需求追踪](../requirements-traceability.md)。

| 需求 | 范围 | 产品要求 |
|---|---|---|
| R4-F01 | 今日任务卡 | 今日卡保留简短来源与可用作者，完整来源留到详情。标题、学习日与实际任务状态可读。 |
| R4-F02 | 多来源文章发现 | 今日、文章库与探索调用同一发现服务，RFC 作为次级入口。展示逐源真实结果，区分检查、入库、无新文和失败。 |
| R4-F03 | 今日库存与标题 | 今日只提供文章库入口和真实总量。标题展示修正常见实体与折行，原元数据继续保存。 |
| R4-F04 | 书库与筛选 | 显示本地总量、当前结果量和四类范围。收藏、稍后独立持久，筛选与空状态及时更新。 |
| R4-F05 | 真实发现进度 | 同次发现共享运行 ID、来源计数、正在处理的来源与阶段、入库、去重和失败。用户明确停止，状态不编造。 |
| R4-F06 | 阅读标题 | 完整标题自然换行，横屏和辅助大字仍能滚动到正文。来源、日期、作者布局紧凑。 |
| R4-F07 | 正文结构 | 按结构清理网页控件，保留正文、标题、引用、列表和图注。旧文章映射可追溯，不改原内容。 |
| R4-F08 | 复习预检 | 所有复习入口共用预检。可处理的缺义允许补录、选义或延期，真正数据损坏明示错误。延期保留原排程。 |
| R4-F09 | 词形与自动保存 | 规范化 user/users、visit/visits，并保留真实词形和句子。输入结束等场景自动保存，支持输入法及失败草稿。 |
| R4-F10 | 连线与语境 | 连线可见并随布局移动，按 ID 匹配，错误、取消和重新选择可分辨。中文来自当前有资格的义项，区分 may 与 May。 |
| R4-F11 | 稳定拼写掩码 | 前中后稳定挖空，常规隐藏约 25%–45% 有效字母，保留标点与分隔符。重新打开使用已保存掩码。 |
| R4-F12 | 复习完成页 | 完成页显示完成数、延期数、继续与返回。历史排程留在次级详情。 |
| R4-F13 | 探索卡片 | 每篇使用单独主题渐变卡。标题、来源、日期、主题和阅读信息在卡内，收藏/稍后与打开分别命中。 |
| R4-F14 | 词汇上下文 | 同源标题和元数据展示一次。保留所有不同原句，支持折叠，来源 URL 归入溯源信息。 |
| R4-F15 | 统一词典详情 | 生词详情和阅读查词复用完整词典。小卡箭头直达全屏，不重复多一层详情。 |
| R4-F16 | 唯一 MDX 来源 | 生产仅使用 Bundle MDX。能区分加载、资源失败、英英和无词结果，无在线字典或自动回退。 |
| R4-F17 | 词汇推荐 | 紧凑显示真实词头/短语、IPA、中文简义。点击读详情，明确加入时才写库。 |
| R4-F18 | 按题反馈 | 反馈与会话、题目、尝试和修订绑定，切题清除旧状态，写入成功再展示结果。 |
| R4-F19 | 揭示后纠正 | 揭示不自动填入或推进。输入完整正确答案才可继续，仍为 Again，重启恢复且排程幂等。 |
| R4-F20 | 设置和关于 | 控件和文本自动持久化，失败保留原值及草稿。关于显示实际版本、构建和开发者。 |
| R4-F21 | 阅读查词浮层 | 小浮层靠近原词，最多两条中文及词性/音标。添加撤销按真实结果，详情关闭后回到原位。 |
| R4-F22 | 完整详情排版 | 三张参考对应词头/IPA、词性和编号义项、用法搭配与双语例句、短语与习语和底部操作。 |
| R4-F23 | 结构化个人词典 | 两个 ZIP 按清单恢复并核验实际资源。真实中文锁个人义，成功缺中文可写结构化义项，故障保留草稿。 |
| R4-F24 | 词义与复习闭环 | 每道题冻结当前义项、真实词形、语境、来源、版本、答案与掩码。个人义须确认，复习评分与恢复遵守相同规则。 |

## 共用要求

- 保留每日周期、原文、个人词义、笔记、阅读位置和历史排程。迁移可回滚，应用故障给出可恢复状态。
- 视觉优先清楚、紧凑并可点。标题与正文可滚动，系统方向、三主题、较大字号和辅助功能都有可复查路径。
- 有中文时所有显示和新题只用 MDX 中文义。成功确定缺中文后的个人义项必须标识来源。词典详细合同独立维护。
