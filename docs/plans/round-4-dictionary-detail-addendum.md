## F22 · 共享详情

| 参考 | 布局要求 |
|---|---|
| IMG_8884 | 衬线词头、确有资料的英美 IPA、系统发音、清晰的词性分组与编号义项 |
| IMG_8885 | 词形及语法标签、缩进的搭配与例句、逐条对应的中文翻译 |
| IMG_8886 | 独立的短语动词和习语区、可用的参见与用法、底部返回/加入/关闭操作 |

生词和查词入口复用详情内容。依据收录的英文身份展示全部适用义项，缺失资料自然省略。去掉重复的详情入口。阅读器小卡按真实结果显示至多两条简义，详情箭头使用独立全屏原生路径。嵌套词条保留返回路径并限制深度。可用动作由实际保存与播放状态驱动。末段内容不能被底部操作挡住，需验证首中末、长词、多义、无例句、个人词、三主题、横屏和辅助大字。

## F23 · 唯一内置 MDX 与个人释义

提交的两个 ZIP 是同一文件的分块。构建用 `merge.py` 核验后将完整 `BundledDictionary.mdx` 放进应用。实际格式、大小与 SHA 见[数据说明](<../../Dictionary Data/README.md>)。原生引擎解析索引、压缩块和内部词条链接。App 仅使用该词典，发音交给系统。无用户字典导入、MDD、在线发音或外部词义回退。

| MDX 状态 | 释义与编辑 | 复习 |
|---|---|---|
| 有中文的真实同身份词条 | 展示 MDX，锁定整词的个人义增删改。笔记独立可编辑，旧个人义项保留为历史。 | 选择匹配语境的 MDX 中文义项。 |
| 只有英文资料、无中文义 | 可保留实际音标、词形等辅助资料，提示缺中文，允许新增结构化个人义。 | 选定并确认满足条件的个人中文义项。 |
| 确认没有词条 | 允许创建带个人标记的词条。 | 确认符合要求后，用同一复习路径。 |
| 加载中 | 显示加载并等待资格结果。 | 新题等待查询结果。 |
| 缺资源、哈希不符或解析失败 | 显示真实错误与重试，保留笔记和草稿，禁止利用故障修改个人义。 | 新题走预检与恢复。已有合法冻结题可依证据恢复。 |

所有当前英文词条对应的中文简义须来自本 MDX 或满足同一资格契约的用户义项。英英解释不可替代中文。MDX 中确有的英文例句、词形与用法仍可使用。来源缓存以 MDX SHA 和解析版本关联，旧提供者的缓存留作历史，不能作为当前中文。短语须用自己的义项及 IPA，例句、译文和备注按例句 ID 一一关联。

个人词头保留规范形与原始形。每义项有 ID、词性、中文释义、顺序、确认状态与修订，支持可选语法、语域、场景、搭配、短语、习语与 IPA 备注。每个义项可独立增删、多例句编辑和修改。用户笔记与题目标准答案分开。无原文的个人词可以用该义自己的可验证例句出拼写题。独立确认与自动保存是两种动作。

资格在 Domain、Service、Repository 和 UI 复用。来源变化时复检当前持久化资格、保存版本和草稿，失效请求不能迟到写入。自动保存覆盖输入、失焦、键盘、切页和后台。存储失败保留有效版本与草稿。旧个人义保持原来源和文本，未确认旧义不自动分配词性或进入新题。

## F24 · 身份、冻结和评分

简明和完整详情、推荐、生词及复习均使用稳定 lexicalIdentity、senseID、meaningRevision 和 meaningOrigin。中文相同并不合并不同身份。出题时冻结真实词形、词性、来源及版本、原文/个人例句、答案、掩码和评分证据。

个人和 MDX 题使用同一连线、拼写与 FSRS 流程。缺词义走预检。延期不算作答。揭示后保留当前题和已有输入，必须亲自输入正确答案才推进，最终 Again。已完成题、有效冻结题和原排程保留，停用来源产生的旧无效题按版本归档并记录重新预检原因。
