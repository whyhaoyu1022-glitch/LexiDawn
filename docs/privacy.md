# 隐私与数据流

个人资料、导入正文、阅读位置、生词、笔记、复习和设置默认只存在设备数据库，不上传。

“从官方来源刷新”只向 RFC Editor 请求固定公开 RFC 8890 URL，不传阅读历史、词汇或个人资料。原文链接由用户主动打开外部浏览器，适用原网站隐私政策。用户填写原 URL 不会触发网页抓取。

开放词典随应用提供，本地 actor 查询，不访问 MDBG 网页，不发送查词上下文。无广告追踪、账户、AI请求或通知安排；这些能力未接入，不仅保存一个开关就宣称已启用。

普通内容/词典缓存处理不删除核心学习记录。用户主动移除词条时软删除，历史复习日志保留。升级前在设备保留数据库备份；不自动上传备份。
