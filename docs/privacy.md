# 隐私与数据流

个人资料、完整导入正文、阅读位置、生词、个人词典/笔记、学习周期、FSRS、日志与设置默认只存在设备数据库，不上传。

文章发现通过已登记的公开 HTTPS 来源获取候选和完整正文；完整性验证及数据库事务通过才保存。失败不降级为摘要或 URL 阅读。不绕过登录、验证码、付费墙。来源元数据保留，日常 UI 仅显示简短来源。

词典查询只读取 App Bundle 中已验证的 MDX，不向 GitHub 或任何在线词典发送词语、上下文或其他请求。系统发音使用设备 AVSpeechSynthesizer；App 不调用发音 API。无用户词典导入、MDD、词典图片/音频资源依赖。个人义项与 MDX 明确区分。

普通缓存清理不删除用户词、个人释义、笔记、周期、已完成/未完成复习、FSRS 和历史。移词软删除，日志保留。升级前保留设备数据库备份，失败保留原库并报错，不自动清库或上传备份。JSON/CSV 仅由用户明确操作系统导出。
