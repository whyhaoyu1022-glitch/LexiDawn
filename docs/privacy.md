# 隐私与数据流

| 数据 | 处理方式 |
|---|---|
| 个人资料、设置、完整原文、阅读位置、词汇、个人词典、笔记、学习周期和排程 | 保存在设备上的应用数据库。LexiDawn 不自动上传。 |
| 文章发现 | 通过 HTTPS 请求源码中登记的公开来源。完整正文通过准入和数据库事务后才入库。处理规则见[完整原文规范](spec-addendum-content-and-dictionary.md)。 |
| 查词和发音 | 查词在设备端读取已验证的内置 MDX，词语和上下文不会发送到词典服务。App 用 iOS 系统语音发音。 |
| 用户导出 | 词汇 JSON/CSV 由用户明确操作，在系统界面选择位置。 |
| 升级和缓存 | 冷启动升级保留设备端数据库备份。缓存可重新生成，个人释义、笔记、未完成周期、进度、排程和历史记录继续保留。 |

完整来源信息保留在数据层及来源详情。真机签名在用户电脑完成，操作见[安装指南](signing.md)。
