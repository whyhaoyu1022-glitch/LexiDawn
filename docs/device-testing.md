# iPhone 真机测试清单

**本轮使用构建 `0.1.0 (215)`，源码 `309bbfd`。** 用 iOS 27.0 或更新版本的 iPhone，通过 AltServer 签名后安装。打开「我的 → 关于词光」核对版本和构建号。[下载未签名 IPA 的 Actions ZIP](https://github.com/whyhaoyu1022-glitch/LexiDawn/actions/runs/44887232103/artifacts/14699989879) · [安装与签名](signing.md) · [已通过的模拟器验证](reviews/round-4-final-delivery.md)

## 选择安装方式

| 设备情况 | 操作 |
|---|---|
| 手机上已有词光，想验证升级 | 先记录旧构建、当前周期、一个阅读位置、一个生词及一项未完成复习。需要留档时先在旧版导出词汇。保留原 App，继续用同一签名账户及包身份覆盖安装。 |
| 手机上还没有词光 | 直接安装，记录首次成功打开的状态。首次联网可自动发现文章。设备离线时使用已安装的 RFC 示例或已导入的本地全文。 |
| 需要同时测干净首启和旧库升级 | 在有旧数据的设备上做覆盖测试，干净首启用另一台可用设备。词汇导出仅包含词汇相关记录。 |

## 先跑一轮核心任务

| 顺序 | 操作 | 应看到的结果 |
|---|---|---|
| 1 · 启动与升级 | 完成签名，开 App，进入「关于」。已覆盖安装时对照升级前的周期、文章、词汇、复习。 | 构建显示 `215`。旧数据和已经进行中的任务可继续。若应用报告存储错误，记录错误原文，保留现有安装。 |
| 2 · 导入自己的短文 | 今日 → 导入 → 确认本地使用授权 → 暂留空标题 → 保存。再补标题和英文正文，收起键盘并保存。示例正文可用下方原文。 | 未授权时保存禁用。授权开启后保存可用，空标题出现校验提示。有效文章出现在书库。本日必做未完成时，仍按原任务门禁打开文章。 |
| 3 · 离线阅读和查词 | 预先打开本地文章再断网。点词，打开完整释义，尝试词典例句继续点词，再返回原文。关闭并重开文章。 | 显示释义或明确查无此词的状态，返回仍在原处。记录首次和连续点词是否明显卡顿，并实际听读系统发音的开始和停止。 |
| 4 · 词汇与个人释义 | 加入生词、查看原句与来源，测试自动加入关闭、移除与重新加入。查 `lexidawngalleryword`，建个人释义和笔记，结束输入后重开验证。 | 含可靠中文的词保留笔记入口，个人释义受限。符合条件的自建词可编辑，中文输入法候选提交后内容可恢复。 |
| 5 · 连线与拼写 | 进入复习。完成一组连线，中途退出再继续。拼写试一次错误或提示，再试揭示并自行输入正确答案。 | 组题与已完成配对可恢复，揭示后须自己纠正，完成页展示实际进度与排程。缺词义时可重查、处理或延期。若实际有 12 个可用词且释义可按默认组量排布，再检查跨板恢复。 |
| 6 · 恢复与可访问性 | 在阅读或复习中切后台再回前台，随后退出重开。横屏、大辅助字号和三种阅读主题分别检查正文、浮窗、关闭。打开 VoiceOver 实际听读。 | 阅读位置和题组保留。模态中的操作可到达，关闭后焦点回到原页面。完整标题、音标和中文能读到，操作仍可触及。 |
| 7 · 书库、导出和长文 | 恢复联网，发起发现，比较今日、书库和探索的结果。试收藏、稍后、搜索、JSON/CSV 导出和长文的多次点词。 | 三个入口反映同一次发现。标记可重开验证。导出的文件可在系统文件应用打开。记录长文滚动和点词的实际表现。 |

可粘贴的短文示例。

> A book opens a window to science. I applied for a library card in May, and the librarian may help me look into a question. I named this small practice session lexidawngalleryword.
