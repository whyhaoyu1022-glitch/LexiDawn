# 完整英文原文的发现、导入与展现

本页保留原补充规范的文章合同。词典规则集中在[词典规范](plans/round-4-dictionary-detail-addendum.md)。旧版全文和词典方案见[归档](archive/README.md#早期规格与历史快照)。

## 准入与来源

1. 只有已取得完整英文正文、通过结构及完整性校验且允许取得、持久化、离线读取和显示的候选，才可进入本地文章库存。
2. RSS、Atom、API、原站列表与用户导入是不同入口。Feed 标题、CDATA、实体与硬换行可以规范化为展示标题。原始标题、来源、可用作者与发布日期保留。
3. 来源跟随[源码登记](../LexiDawn/Domain/Learning/PublisherSources.swift)及[来源审查记录](article-source-eligibility-audit.md)。正规来源资格、负责人个人模式、用户自有内容分别保存依据。登录、验证码、付费墙与拒绝访问按失败处理。
4. 临时候选只用于发现与去重。全文取不到，或正文仅有摘要、付费提示、错误页面、水印控件或不完整末尾，就放弃本次候选。失败不存成可读文章，不提供跳转原站、链接、摘要或 WebView 降级。
5. RFC 8890 属于随附的独立全文示例及核验刷新路线。粘贴导入需有明确授权确认，原 URL 用于溯源和去重，阅读始终使用本地正文。

## 发现与入库

- 今日、文章库和探索订阅同一个 `ArticleDiscoveryService`。每次发现有运行 ID，逐源记录访问阶段、成功/无新文章/限流/失败、已处理数、导入及去重计数。未知下载字节量不换算成进度百分比。退出页面不取消共享任务，显式停止保留已提交结果。
- 同源解析保留正文自然段落、标题、引用、列表和有意义的图注。播放器占位、Cookie、分享、脚本与导航按 DOM 结构和来源规则清理。不得用关键词删除正常报道。
- 采用规范 URL、正文哈希等稳定身份去重。事务保存正文、结构、版本和真实元数据。保存失败保留既有库存。入库后再次检查实际可读性，来源统计以实际提交为准。
- 本地文章记录关联来源 ID、规范 URL、原始标题、可用作者、发布日期/抓取时间、原文、结构化块、正文 SHA、英文词数、阅读估时、真实主题、准入证据和提取版本。进入阅读器核验内容状态、访问权利与缓存期限。历史元数据与可展示正文的有效性分别记录。
- 每日候选根据主题、完整度、来源、篇幅、新鲜度与学习价值排序。目标篇幅参考约 1,200–2,500 英文词，阅读估时基于词数。新候选不能替换已分配的有效正文或覆盖未完成周期。

## 显示与恢复

原生阅读器以结构化块自然分段，支持标题换行、阅读主题、动态字号、横屏和点词。旧正文的清理使用版本化展示投影，维护到原始 UTF-16 区间的映射。原文、哈希与历史偏移保留。阅读位置跨版本恢复仅在原段落能明确匹配时进行。

今日和生词默认只显示简短来源。完整作者、来源 URL 和准入元数据保留在来源详情、数据库和适用的导出中。按[文章验收](plans/round-4-development-specification.md)及[测试计划](test-plan.md)核对真实来源、失败处理与本地读回。
