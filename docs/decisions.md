# 技术决策

ADR 沿用原编号。表格记录仍需了解的取舍，原文和早期替代方案可在[归档入口](archive/README.md#早期规格与历史快照)打开。

| 决策 | 做法 | 原因或适用边界 |
|---|---|---|
| ADR-001 · 原生应用 | SwiftUI 配合必要 UIKit，数据和学习规则留在 Domain/Service/Repository | 保留系统交互与辅助功能，避免重复业务规则。 |
| ADR-002/003 · 平台与 CI | 生产目标 iOS 27.0。Xcode 26.6 的 iOS 26.5 Simulator 作为兼容验证 | 兼容测试与真机安装需要独立证据。 |
| ADR-004/005 · 完成证据与历史状态 | 阅读完成与文章版本绑定。空队列需来自完整候选集合。已知无证据的旧终态归档后置为阻塞 | 损坏、未接入、缺义和空队列含义不同。 |
| ADR-006 · 跨日与时钟 | Gregorian 本地学习日期加高水位。按实际经过的日期计数，原分配时区保留。 | 冷启动、旅行、夏令时和时钟回拨不重记。 |
| ADR-007/009 · 数据升级和写入 | 打开容器前备份。一笔业务使用独立上下文，失败回滚并弃用 | 避免失败写入在同上下文形成幽灵记录。单应用串行写入是当前边界。 |
| ADR-008 · 事件时间和正文资格 | 学习结果按原事件时间记账。完成凭据单调且幂等。展示与缓存资格分别记录 | 保留历史结果和源证据，失败和回拨不会凭空恢复权限或进度。 |
| ADR-010/012 · 原生布局证据 | 由实际 Launch Screen 和 Scene 配置生成窗口。长文用 TextKit 词元桥接，短文本用原生链接 | 用实际窗口、命中与截图判断辅助功能，静态代码赋值本身不足以证明。 |
| ADR-011 · 本地学习 | 正文读出口重复验证准入，学习天数按明确阅读或真实非空复习事件统计，嵌套词条有深度限制 | 早期反向词典和基础排程已由 MDX 与 FSRS 4.5 取代。 |
| ADR-013 · 唯一内置 MDX | 构建时按原清单恢复单文件，运行时 actor 与原生解析器从 Bundle 读取。仅成功无中文或无词允许个人义 | 资源故障独立报错。旧缓存与个人历史保留，启用资格重新校验。 |
| ADR-014 · 原图与可恢复阅读 | 旧正文用可追溯展示投影。词典复用同一共享布局。证据绑定实际构建、设备、方法与图片哈希 | 阅读位置可核对。验收按同一提交的真实证据理解。 |

实现位置与运行限制见[架构](architecture.md)，当前交付结论见 [STATUS](../STATUS.md)。
